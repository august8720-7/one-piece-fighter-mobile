# 双手机实测0927

这是已发布手机预览的实际设备操作单。尚无手机结果，以下步骤不代表通过；同机浏览器证据不能填入本表。先确认能连接，再做后续专项，遇到阻断先修相关问题。

## 先进入同一局

1. 两台手机连接同一普通 Wi-Fi，横屏，用各自浏览器打开 https://august8720-7.github.io/one-piece-fighter-mobile/ 。先保留互联网连接，房间配对需要免费信令服务。
2. 手机A：点“创建房间”，选择LABUBU，再点“创建房间”，保留页面上的10位码。
3. 手机B：点“加入房间”，选择星星人，输入A的10位码，点“连接房间”。
4. 两边都应显示对方已加入。双方点“准备”，等各自资源加载后，确认进入同一局。
5. A移动并出拳，B释放小星弹；两端应看到相同角色在行动、相同受击和血量变化。记录卡在哪一步或页面原文，不将创建房间成功当成对战成功。

## 连通后再完成剩余要求

- 真实触控与声音：分别试方向和攻击同时按、短按、拖过方向按钮间隙、松手停止；确认手指不会粘键、九个技能可触达。大招仍需要气槽，灰色不可用不代表触控失效。检查人物语音、打击声和BGM能否听见。
- 完整流程：打到结算，两端胜者一致；点再战、双方重新准备；再通过换角至少实际载入一次不同角色组合。
- 暂停与恢复：一方暂停，另一方也应停；继续后双方同步。一次短暂切后台或转竖屏应暂停并清键，回到横屏后再继续。若浏览器实际关闭了连接，应明确停局并重新配对，不要求旧局无损恢复。
- 断线：一方退出，对端应显示本局停止；两端重新创建/加入后能开始新局。
- 热点：记录哪台手机提供热点、哪台加入；按前述最短路径再次确认双方实际开打。若热点本身限制设备互通，如实记录该环境不支持，不更改系统安全设置来凑通过。
- 连续对战：上述关键路径无阻断后，用真实两手机前台对战15分钟，记录开始/结束时间、实际完成场次和遇到的故障。不要用后台空等、电脑回放或菜单停留冒充持续比赛。
